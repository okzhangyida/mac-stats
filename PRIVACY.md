# Mac Stats Privacy Policy

Effective date: August 26, 2026

Mac Stats is designed to monitor the Mac on which it is running. It does not require an account and does not include advertising, analytics, telemetry, or crash-reporting SDKs.

## Data processed on your Mac

To provide its features, Mac Stats reads system resource usage, hardware details, thermal and fan sensor values when available, battery status, network throughput, and process names or executable paths. These values are displayed locally and are not transmitted to the developer or any third party.

App preferences—such as refresh interval, appearance, memory accounting, launch-at-login, and menu bar selections—are stored locally using macOS preferences.

## Collection and sharing

Mac Stats does not collect, upload, sell, or share personal data. It does not contact a remote analytics service. The application currently has no network-based account or synchronization feature.

## Retention

Live samples are held in memory only as needed to render the interface. Preferences remain on the Mac until the user changes them or removes the app’s local preferences.

## Changes

If a future version introduces any network service or changes this policy, the policy and release notes will be updated before that version is distributed.

Publisher and support contact details will be added before the notarized public download is opened.
