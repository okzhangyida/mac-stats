# Mac Stats 1.0.0 — build 20261008.02

- 修复空白“Mac Stats 设置”窗口：移除内容为空的 SwiftUI Settings 场景，统一由 AppKit 管理设置入口，并禁止系统自动恢复设置窗口。
- 菜单栏文字采用 macOS 标准菜单栏字体。
- 构建脚本支持独立缓存路径，避免项目目录迁移后的旧缓存路径影响编译。

支持 macOS 13 及以上，Universal（Apple silicon + Intel），Developer ID 签名并经 Apple 公证。

验证：17 项自动测试通过，覆盖设置窗口重复打开、关闭后重新创建完整内容，以及明暗主题渲染。长时间熄屏后的实际使用表现仍待持续观察。

本机测试版为 build 20261008.01；本正式发布使用独立 build 20261008.02，CFBundleVersion 为 2610.8.2。
