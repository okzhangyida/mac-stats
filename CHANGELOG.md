# Changelog

## 1.0.0

First public release of Mac Stats for macOS 13 and later.

- Menu bar system monitoring and a native dashboard.
- Notch blending, dark menu bar, and rounded desktop corners.
- CPU, memory, network, battery, temperature, fan, and process views.
- English and Simplified Chinese, with light and dark appearance.
- Universal download for Apple silicon and Intel Macs.
